How do I find the group's chat ID manually?
  1. Create a Telegram group (or use an existing one) and add your bot to it
  2. Send any message in that group
  3. Click "Detect from bot activity" above, or open https://api.telegram.org/bot<BOT_TOKEN>/getUpdates in a browser and find "chat":{"id": -100123456789} (group IDs are negative)
